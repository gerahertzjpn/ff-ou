# ff-ou

[日本語](README.md) | [English](README.en.md)

ターミナル上で動く ASCII グラフィックの RPG です。
Python と [asciimatics](https://github.com/peterbrittain/asciimatics) で作っている個人プロジェクトで、現在も開発中です。

```text
:::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::
:#............###########.#      :quests                          :
:......##########.........#      :(X) first                       :
:########..........########      :( ) back                        :
:.........................#      :                                :
:..................T......#      :                                :
:.........................#      :                                :
:.........................#      :                                :
:.........................#      :                                :
:................$........#      :                                :
:.........................#      :                                :
:.........................#      :                                :
:.........................#      :                                :
:.........................#      :                                :
:.........................#      :                                :
:.........................#      :                                :
:.........................#      :           < 1 / 5 >            :
:::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::
```

左側がマップ（`$` が主人公、`#` が壁）、右側がサイドメニューです。

## 主な機能

- **主人公を中心にスクロールするマップ**：テキストファイル（`mapLight.txt`）からマップを読み込み、主人公の周りの 32×16 マスだけを表示します。
- **当たり判定**：壁（`#`）などの通れないマスには移動できません。
- **再利用できるメニュー UI**：選択式のリストを `FatherList` クラスとして作り、それを継承した `SideScreen` クラスでページ切り替えと「閉じる」操作を追加しました。見出しの行はカーソルが自動的に飛ばします。
- **5 ページのサイドメニュー**：quests / equipment / items / skills / stats（中身はこれから実装します）。
- **戦闘システムのプロトタイプ**（`fight.py`）：通常攻撃・スキル・アイテム・逃げるの 4 つの行動があり、ダメージはランダムで決まります。

## 使用技術

| 技術 | 用途 |
|---|---|
| Python 3 | 開発言語（3.14 で動作確認済み） |
| [asciimatics](https://github.com/peterbrittain/asciimatics) | ターミナルへの描画とキー入力 |
| [cutie](https://github.com/kamik423/cutie) | 戦闘プロトタイプ（`fight.py`）の選択メニュー |

## 起動方法

```bash
git clone https://github.com/gerahertzjpn/ff-ou.git
cd ff-ou

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
python game.py
```

- マップなどのファイルを相対パスで読み込むので、**リポジトリのルートで**実行してください。
- ターミナルは 80×24 文字以上をおすすめします（ゲーム画面は 67×18 文字です）。
- 戦闘のプロトタイプは単体で動きます：`python fight.py`

## 操作方法

| 画面 | キー | 動作 |
|---|---|---|
| メインメニュー | ↑ / ↓ | 項目を選ぶ |
| | Enter | 決定 |
| マップ | ← ↑ ↓ → | 移動 |
| | E | サイドメニューを開く |
| | Esc | ゲームを終了する |
| サイドメニュー | ↑ / ↓ | 項目を選ぶ |
| | ← / → | ページを切り替える（1〜5） |
| | Q | メニューを閉じてマップに戻る |

## ファイル構成

| ファイル | 内容 |
|---|---|
| `game.py` | エントリーポイント。初期化、メインループ、主人公の移動 |
| `map.py` | マップの読み込みと描画、サイド画面、メニュー UI（`FatherList` / `SideScreen`） |
| `mainmenu.py` | メインメニュー（play / settings / exit） |
| `fight.py` | 戦闘システムのプロトタイプ（単体で実行） |
| `mapLight.txt` | ゲームで使っているマップ |
| `map.txt` | 大きな迷路のマップ（現在は未使用） |
| `secondscreen.txt` | サイド画面用のテキスト |
| `settings.py` / `sidescreen.py` | 旧バージョンと実験用のコード（コメントアウト済み） |

## 開発の流れ

1. シンプルなテキストメニューから始め、`curses` と `cutie` でマップの表示と主人公の移動を作りました。
2. 描画とキー入力を `asciimatics` に移す、大きなリファクタリングを行いました。
3. 選択式リストを関数からクラスに書き直し、サイド画面にインタラクティブなメニューを追加しました。

## 開発メモ

- ゲーム内のテキストは英語（ASCII）で統一しています。全角文字はターミナル上で 2 マス分の幅になり、マス目単位のレイアウトが崩れてしまうためです。
- サイド画面に表示できるのは 1 行 32 文字までです。長いテキストは手動で改行してください。
- マップとサイド画面の表示サイズは、どちらも 32×16 マスで固定です。
